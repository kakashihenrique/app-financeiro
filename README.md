# App Financeiro

Aplicativo Android de calculadora financeira desenvolvido em Kotlin e Jetpack Compose para trabalho da faculdade.
https://github.com/kakashihenrique/app-financeiro/tree/main
## Calculadoras

- Salario liquido
- Ferias
- 13o salario
- Rescisao CLT
- Horas extras
- FGTS
- Simples Nacional / DAS
- Lucro Presumido
- Lucro Real
- ICMS interestadual
- Pro-labore

## Como rodar

1. Abra o Android Studio.
2. Selecione a pasta "ONDE SE LOCALIZA O APP".
3. Aguarde o Gradle sincronizar.
4. Instale o Android SDK 34 se o Android Studio pedir.
5. Clique em Run.

Os calculos usam tabelas trabalhistas de referencia para 2026 e devem ser tratados como estimativas.
